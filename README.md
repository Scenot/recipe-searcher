# Recipe Searcher

A command-line recipe finder built with Python.

## Features

- Search recipes by dish name
- Fetch data from TheMealDB API
- Display name, category, cuisine, and instructions
- Save search history to SQLite

## How to Use

    python recipe.py

## How to Test

    pytest test_recipe.py

## Requirements

- Python 3.8+
- `requests` library

## Setup

    pip install requests
